# VEILOS 30-Second Pitch

Every application we install asks us to trust our device with it.

What if applications were guests instead of owners?

VEILOS is a live, disposable Linux operating system built for ephemeral computing. Sandboxes run entirely in volatile memory with unprivileged kernel namespaces and zero host access.

Use the application, close the session, and your data is cryptographically destroyed with zero forensic traces left behind.

VEILOS: Private Computing by Default.
